Luv Diag Face 0.1.0 — тестовый циферблат для Amazfit Bip Max. Парный к приложению Luv Diag (архив LuvDiag-v1.zip).
Рисует только текст: что циферблат может прочитать из общей памяти часов (данные Luv Diag и Luv Sync), может ли он сам
писать в общую память, есть ли у него таймеры и «наблюдатель» возврата на экран.

КАК УСТАНОВИТЬ: как обычно — НОВЫЙ репозиторий, всё из папки, .github/workflows/build.yml из файла build.yml,
Settings -> Pages (ветка gh-pages), QR-код "square-432x514" в Zepp -> Режим разработчика. Затем выбрать циферблат.
Ставьте после Luv Diag. Свой настоящий циферблат (Luv Face) этот проект не трогает — потом просто вернёте его.

КАК ПОЛЬЗОВАТЬСЯ: сначала пройдите проверки в Luv Diag (в особенности «2 Запись» и «5 Служба»), потом выберите этот циферблат
и пришлите фото экрана. Через пару секунд после включения экрана строки обновятся.
